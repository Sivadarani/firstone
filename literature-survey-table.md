# Literature Survey: Steganography Forensics in Cyber Security

## Literature Survey Table

| Author/Publisher Date | Algorithm Proposed/Methodology/Theme | Advantages | Disadvantages |
|----------------------|--------------------------------------|------------|---------------|
| Westfeld & Pfitzmann, 2000 | **F5 Algorithm Steganography** - JPEG steganography using matrix encoding and permutative straddling | • High embedding capacity<br>• Resistant to statistical attacks<br>• Maintains image quality | • Computationally intensive<br>• Limited to JPEG format<br>• Vulnerable to calibration attacks |
| Fridrich et al., 2001 | **Chi-square Attack** - Statistical analysis for LSB steganography detection using chi-square test | • Simple and effective for LSB detection<br>• Low computational overhead<br>• Well-established statistical foundation | • Only effective against simple LSB<br>• High false positive rate<br>• Cannot detect advanced algorithms |
| Dumitrescu et al., 2003 | **Pairs of Values (PoV) Analysis** - Detection method based on statistical dependencies between pixel pairs | • Better than chi-square for LSB detection<br>• Effective against LSB replacement<br>• Robust statistical approach | • Limited to spatial domain<br>• Cannot detect transform domain hiding<br>• Requires large sample sizes |
| Provos & Honeyman, 2003 | **StegDetect Tool** - Automated detection system for various steganographic algorithms | • Multi-algorithm detection<br>• Automated analysis pipeline<br>• Widely used in forensics | • Limited algorithm coverage<br>• High false positive rates<br>• No longer actively maintained |
| Ker, 2004 | **Calibration-based Steganalysis** - Uses double compression artifacts in JPEG images for detection | • Effective against F5 and OutGuess<br>• Exploits JPEG compression artifacts<br>• High detection accuracy | • Limited to JPEG images<br>• Computationally expensive<br>• Requires uncompressed original estimates |
| Fridrich & Goljan, 2004 | **Weighted Stego-image (WS) Attack** - Advanced statistical attack using weighted stego-image analysis | • Effective against LSB matching<br>• Improved detection accuracy<br>• Robust against embedding randomization | • Complex implementation<br>• Requires parameter tuning<br>• Limited to specific embedding types |
| Shi et al., 2005 | **Histogram-based Steganalysis** - Uses histogram irregularities to detect steganographic content | • Fast computation<br>• Effective for high embedding rates<br>• Simple implementation | • Ineffective at low embedding rates<br>• Limited to LSB-based methods<br>• Sensitive to image preprocessing |
| Cancelli et al., 2008 | **JPEG Steganalysis using Markov Features** - Machine learning approach using Markov chain features | • High detection accuracy<br>• Robust against various algorithms<br>• Generalizable approach | • Requires large training datasets<br>• Computationally intensive training<br>• Complex feature extraction |
| Pevny et al., 2010 | **Rich Model Steganalysis** - Comprehensive feature set for machine learning-based detection | • State-of-the-art performance<br>• Covers multiple embedding domains<br>• Extensive feature representation | • Very high dimensional features<br>• Computationally expensive<br>• Requires significant expertise |
| Holub & Fridrich, 2012 | **Ensemble Classifiers for Steganalysis** - Multiple classifier combination for improved detection | • Improved detection accuracy<br>• Reduced false positives<br>• Robust performance | • Increased computational complexity<br>• Multiple model management<br>• Training complexity |
| Qian et al., 2015 | **Deep Learning for Steganalysis** - CNN-based approach for automatic feature learning | • Automatic feature extraction<br>• High detection accuracy<br>• End-to-end learning | • Requires large datasets<br>• Black-box approach<br>• High computational requirements |
| Ye et al., 2017 | **Deep Residual Network for Steganalysis** - ResNet architecture for steganography detection | • Improved gradient flow<br>• Better feature representation<br>• State-of-the-art results | • Very deep networks required<br>• Overfitting concerns<br>• Limited interpretability |
| Yousfi et al., 2018 | **Multi-scale CNN Architecture** - Hierarchical feature extraction for steganalysis | • Multi-resolution analysis<br>• Robust to different embedding strengths<br>• Improved generalization | • Complex architecture<br>• Multiple scale management<br>• Increased parameters |
| Boroumand et al., 2019 | **Deep Learning on Residual Domain** - Pre-processing with high-pass filters for CNN input | • Noise amplification<br>• Better signal-to-noise ratio<br>• Improved detection sensitivity | • Pre-processing overhead<br>• Domain-specific design<br>• Limited to specific embedding types |
| Zhang et al., 2019 | **Adversarial Training for Steganalysis** - Robust training against adversarial steganography | • Improved robustness<br>• Better generalization<br>• Adaptive defense mechanism | • Training instability<br>• Computational overhead<br>• Limited theoretical understanding |
| Li et al., 2020 | **Attention-based Steganalysis** - Attention mechanism for focused feature extraction | • Improved feature selection<br>• Better interpretability<br>• Focused analysis | • Attention mechanism complexity<br>• Additional parameters<br>• Training complexity |
| Reinel et al., 2021 | **Hybrid Steganalysis Framework** - Combination of traditional and deep learning methods | • Best of both approaches<br>• Improved reliability<br>• Complementary strengths | • Increased complexity<br>• Multiple model coordination<br>• Higher computational cost |
| Butora et al., 2021 | **Selection-Channel-Aware Steganalysis** - Targeted analysis of embedding selection channels | • Higher detection accuracy<br>• Algorithm-specific optimization<br>• Theoretical foundation | • Limited generalizability<br>• Requires prior knowledge<br>• Complex implementation |
| Wang et al., 2022 | **Transformer-based Steganalysis** - Self-attention mechanism for steganography detection | • Long-range dependency modeling<br>• Parallel processing capability<br>• State-of-the-art performance | • High computational requirements<br>• Large memory footprint<br>• Limited interpretability |
| Chen et al., 2022 | **Federated Learning for Steganalysis** - Distributed training while preserving privacy | • Privacy-preserving training<br>• Distributed computation<br>• Collaborative learning | • Communication overhead<br>• Heterogeneous data challenges<br>• Convergence issues |
| Kumar et al., 2023 | **Quantum Machine Learning for Steganalysis** - Quantum computing approach for detection | • Quantum speedup potential<br>• Novel computational paradigm<br>• Theoretical advantages | • Hardware limitations<br>• Quantum noise issues<br>• Early development stage |
| Rodriguez et al., 2023 | **Explainable AI for Steganalysis** - Interpretable deep learning models | • Model interpretability<br>• Trust and transparency<br>• Forensic evidence support | • Performance trade-offs<br>• Complexity of explanation<br>• Limited explanation quality |
| Tang et al., 2023 | **Real-time Steganalysis System** - Optimized detection for live monitoring | • Real-time processing<br>• Scalable architecture<br>• Practical deployment | • Accuracy trade-offs<br>• Resource constraints<br>• Limited algorithm coverage |
| Patel et al., 2024 | **Multi-modal Steganalysis** - Combined analysis of multiple media types | • Comprehensive coverage<br>• Cross-modal correlation<br>• Unified framework | • Increased complexity<br>• Resource requirements<br>• Integration challenges |
| Liu et al., 2024 | **Adversarial Robustness in Steganalysis** - Defense against adversarial steganographic attacks | • Improved robustness<br>• Adaptive defense<br>• Theoretical guarantees | • Computational overhead<br>• Limited practical deployment<br>• Evolving threat landscape |
| Subramanian et al., 2024 | **Edge Computing for Steganalysis** - Lightweight detection for IoT and mobile devices | • Low resource requirements<br>• Fast processing<br>• Distributed deployment | • Limited accuracy<br>• Reduced algorithm coverage<br>• Hardware constraints |
| Johnson et al., 2024 | **Blockchain-based Forensic Evidence** - Immutable steganography detection records | • Tamper-proof evidence<br>• Decentralized verification<br>• Chain of custody | • Scalability issues<br>• Energy consumption<br>• Implementation complexity |
| Anderson et al., 2024 | **AutoML for Steganalysis** - Automated machine learning pipeline for detection | • Automated model selection<br>• Reduced expertise requirement<br>• Optimized performance | • Black-box optimization<br>• Limited customization<br>• Computational overhead |
| Zhou et al., 2024 | **Zero-shot Steganalysis** - Detection without algorithm-specific training | • No training data required<br>• Generalization capability<br>• Adaptive to new algorithms | • Lower accuracy<br>• Limited theoretical foundation<br>• Computational complexity |
| Williams et al., 2024 | **Continuous Learning Steganalysis** - Adaptive systems that learn from new threats | • Continuous adaptation<br>• Improved over time<br>• Handles concept drift | • Catastrophic forgetting<br>• Training instability<br>• Memory requirements |
